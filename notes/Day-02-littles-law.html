Little's Law
为什么是严谨的

把 CLI 里那套面积推导搬进浏览器看。L = λW 不是经验拟合 —— 它能被严格证明，而且严谨性精确地锚在一步上：非负函数的求和与积分可以交换。

1结论先行

两个尺度，两种答案

你的数学嗅觉很准：在任何有限时间窗口里，L = λW 确实只是近似（窗口末尾总有几个还没离开的请求被截断）。它精确成立，是作为 T → ∞ 的长期平均极限。两种感觉都对，只是对应不同尺度。

一句话定位
  • 有限窗口 → 近似（边界截断带来 O(1) 误差）。
  • 长期平均极限 → 精确，且证明只用到一个非负函数恒等式 + 系统稳定。
  • 它甚至不是一个概率定理 —— 对任意一条样本轨迹都成立。
2一张图

同一块面积，两种数法

取观察窗 [0, T]。每个请求 i 是一条水平线段：从到达 ai 画到离开 di，长度正好是它的停留时间 Wi。把这些线段覆盖的总面积故意用两种方式数 —— 答案必须相等。

注意那条 t = 2.5 的竖线：它在上面板穿过 r1 / r2 / r3 三条线段，对应下面板此刻的 N = 3。竖切一刀切到几条线，就是那一刻系统里有几个请求。

3推导

把「面积相等」写成等式

定义 L̄ 为时间平均的在途请求数，N(t) 为 t 时刻系统内请求数，1[·] 为指示函数（条件成立取 1，否则取 0）。整条推导就四步：

L̄  ≡  (1/T) ∫0T N(t) dt 时间平均的"在途数"——竖着积分整条 N(t) 曲线
∫0T N(t) dt  =  ∫0T Σi 1[ai ≤ t < di] dt N(t) 不过是"此刻有几条线段盖住 t"
         =  Σi ∫0T 1[ai ≤ t < di] dt ★ 交换 Σ 与 ∫ —— 整个定律就靠这一步
         =  Σi (di − ai)  =  Σi Wi  =  A · W̄ 每条线段积出自己的长度 = 停留时间 Wi；A 个请求、平均 W̄

把第一行和最后一行接起来，再用到达率 λ = A / T：

L̄ = (1/T)·A·W̄ = (A/T)·W̄ = λ·W̄

（A = 窗口内的请求数，W̄ = 平均停留时间，λ = 到达率）

4严谨性

严谨性锚在哪一步

整条推导里唯一"有技术含量"的，是第 3 步交换求和与积分。它合法吗？合法 —— 而且是无条件合法：

Tonelli 定理

被积的是指示函数，恒为非负。对非负函数，求和（其实是对计数测度积分）与积分总是可以交换次序——这正是 Tonelli 定理的结论。不需要任何概率假设、不需要分布、不需要收敛性前提。这一步站得住，整个 L = λW 就站得住。

所以它的严谨性不是"工程经验"，而是落在一条标准的测度论定理上。这也解释了为什么它长得这么朴素却滴水不漏。

5普适性

为什么它适用范围广得离谱

回看整条推导：从头到尾没用到请求服从什么到达分布、服务要花多久、有几个服务台、是先到先服务还是后到先服务。它只是在数面积。

一个恒等式，不是一个概率定律

因为不依赖任何随机假设，它对任意一条具体的样本轨迹都成立 —— 你拿真实日志里那一串到达/离开时间戳直接算，等式就精确成立。这就是它"简单得让人怀疑"的根源：它确实极普适，普适到不像一个需要证明的东西。

6前提

你的直觉对在哪：边界与稳定性

上面的推导偷偷假设了所有请求都在 [0,T] 内完整地来了又走。真实窗口里总有几个"到 T 时刻还赖着没走"的请求，它们的线段在右边被截断 —— 这就是有限窗口下 L = λW 只是近似的原因，也正是你闻到的那股"不严谨"味。

边界项怎么处理

那些被截断的请求只有 O(1) 个（一小撮），而总量是 O(T)。误差除以 T，当 T → ∞ 趋于 0。严格陈述（Stidham 的 sample-path 版本）：只要 λ = lim A(T)/T 和 W̄ = lim (1/A)ΣWi 这两个极限存在且有限，那么 L̄ 必然存在且 L̄ = λW̄。

唯一的前提就一句话：系统稳定（长期进出平衡，队列不无限涨）。否则 L 会一直累积、极限不存在，公式自然失效。这正呼应了 Day-02 那句"逼近吞吐上限时队列堆积、W 暴涨"——那就是稳定性被打破、Little's Law 前提开始失灵的地方。

✓数值校验

用图里那个例子收尾

QuoteFlow · 抽象成 5 个请求

就用上面 SVG 里的五条线段（时间单位任意，可想成"百毫秒"）。把三条平均值各自独立算出来，再看 L = λW 对不对得上：

请求数 A = 5，观察窗 T = 8
到达率 λ = A/T = 5/8 = 0.625
总停留 Σ Wi = 15 → 平均 W̄ = 3
面积平均 L̄ = (∫N dt)/T = 15/8 = 1.875
λ · W̄ = 0.625 × 3 = 1.875  =  L̄  ✓

三个量是各自独立算出来的，却严丝合缝。把它放到真实的 QuoteFlow 上：实时报价 λ = 500 QPS、W = 0.2s → 任意时刻约 L = 100 个请求在飞，线程池 / 连接数就按 100 备，而不是按 500。

A→Z术语表

这页用到的词

Little's Law
L = λ × W：系统内平均并发数 = 到达率 × 平均停留时间。长期平均下精确成立。
Indicator 1[·]
指示函数：括号内条件成立取 1、否则取 0。用它把 N(t) 写成一串线段的叠加。
Tonelli 定理
对非负函数，求和与积分（多重积分）可无条件交换次序。本页严谨性的落点。
Sample-path 证明
不靠概率假设、对单条真实轨迹就成立的证明。Little's Law 即属此类。
Stability（稳定）
长期到达≈离开、队列不无限增长。Little's Law 成立的唯一前提。
Boundary effect
有限窗口末尾未离开请求带来的 O(1) 截断误差；T→∞ 时可忽略。
